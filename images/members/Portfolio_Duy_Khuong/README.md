# Portfolio cá nhân — Duy Khương

## Chạy trên VS Code
1. Giải nén `Portfolio_Duy_Khuong.zip`.
2. Mở thư mục `Portfolio_Duy_Khuong` bằng VS Code.
3. Mở `index.html` bằng trình duyệt (hoặc dùng extension Live Server).
4. Giữ nguyên cấu trúc thư mục `css`, `js`, `images`.

## Cấu trúc
- `index.html`: cấu trúc nội dung.
- `css/style.css`: giao diện, responsive và animation.
- `js/main.js`: menu mobile, dark mode, hiệu ứng reveal, lọc dự án, modal và kiểm tra form.
- `images/sky-background.png`: background bầu trời (nếu file được đính kèm trong gói).

## Trước khi nộp bài
- Thay email mẫu `your.email@example.com`, liên kết GitHub và nội dung cá nhân bằng thông tin thật.
- Cập nhật trường học, ngành học, hoạt động, chứng chỉ và mục tiêu nghề nghiệp.
- Đưa ảnh chụp và liên kết source/demo thật vào từng dự án. Nội dung dự án hiện tại là nội dung mẫu để minh họa bố cục.
- Thanh form hiện chỉ kiểm tra dữ liệu phía trình duyệt, chưa gửi email thật. Muốn gửi thật cần tích hợp backend hoặc dịch vụ form.
- Kiểm tra trên desktop, tablet và mobile.

## Các tương tác đã có
1. Menu điều hướng mobile.
2. Dark mode / light mode, lưu lựa chọn trong localStorage.
3. Hiệu ứng reveal khi cuộn trang.
4. Lọc dự án theo danh mục.
5. Modal chi tiết dự án.
6. Nút cuộn về đầu trang.
7. Kiểm tra dữ liệu form liên hệ bằng JavaScript.
